📋 配置步骤

1
提取配置（在你的 Windows 电脑上运行） 
python extract_config.py
这会自动从 TRAE 桌面端提取认证信息，生成 config.json
2
填写用户信息
打开 config.json，填入你的 user_id 和 username
从 TRAE 仪表盘 URL 获取：user_id=xxx&username=xxx
3
启动服务 
python serve.py
浏览器会自动打开监控面板

🔑 获取 user_id 和 username

1. 打开 TRAE 仪表盘

2. 复制浏览器地址栏中的 URL

3. 找到 user_id=xxx 和 username=xxx 部分

4. 填入 config.json 对应字段

检查配置状态
注意：config.json 包含你的认证信息，请勿公开分享。 建议将 config.json 加入 .gitignore。
